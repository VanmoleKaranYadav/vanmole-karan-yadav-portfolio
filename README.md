# Vanmole Karan Yadav — Full-Stack Portfolio

A production-ready full-stack personal portfolio web application for **Vanmole Karan Yadav**, showcasing engineering works, academic background, applied AI internship, hackathon achievements, and contact channels.

---

## 🚀 Features

- **Frontend**: Built with **React 18**, **Vite**, and **Tailwind CSS**.
- **Dark & White Mode**: Seamless dual-theme switcher with instant Zero-FOUC initialization.
- **Backend API**: **Node.js & Express.js** server providing:
  - `POST /api/contact`: Form validation, input sanitization, rate limiting, and persistent message recording.
  - `GET /api/resume`: Direct streaming of official resume PDF.
  - `GET /api/portfolio`: Structured JSON endpoint for portfolio data.
  - `GET /api/health`: Health monitoring endpoint.
- **Featured Projects**:
  - **Organ Donor Service System**: Full-stack MERN healthcare coordination platform.
  - **AgriPath AI**: Agritech intelligence platform with predictive advisory models.
- **Standalone Version**: Includes `karan-minimal-portfolio.html` for single-file portable viewing.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Lucide React
- **Backend**: Node.js, Express.js, CORS, Dotenv
- **Tooling**: Concurrently, PostCSS, Autoprefixer

---

## 📦 Getting Started

### 1. Installation

```bash
npm install
```

### 2. Development

Runs both the frontend dev server and the backend API server concurrently:

```bash
npm run dev
```

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`

### 3. Production Build & Start

```bash
npm run build
npm start
```

Runs the production Express server serving both static frontend assets and API routes on `http://localhost:5000`.
